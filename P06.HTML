TrollStore Supported Devices: Compatible iPhone & iPad Models

Evaluate iPhone and iPad compatibility by chip architecture, iOS/iPadOS version, build number, and installation method.

Whether an iPhone or iPad can run TrollStore depends on three intersecting factors: the installed iOS or iPadOS version (including exact build numbers for edge cases), the device's processor architecture (arm64 vs. arm64e), and whether a valid installation route exists for that exact pairing.

Officially documented TrollStore support covers iOS/iPadOS 14.0 beta 2 through 16.6.1, iOS/iPadOS 16.7 RC (build 20H18), and iOS/iPadOS 17.0. Firmware releases such as public 16.7, 17.0.1 and later, and iOS/iPadOS 18+ fall outside the documented support range.

Key Rule of Thumb: A newer iPhone or iPad is not automatically supported if its firmware has already passed iOS/iPadOS 17.0 (except the specific 16.7 RC 20H18 build). Conversely, an older model that never reached supported firmware—or is stuck on an unsupported version—cannot use TrollStore.

How Device Compatibility Is Determined

TrollStore relies on CoreTrust code-signing vulnerabilities rather than raw CPU speed or screen size. Because Apple patched those vulnerabilities in later firmware builds, compatibility is bounded by operating system history first and hardware architecture second.

  • Firmware overlap: The device's current iOS or iPadOS version must fall within the supported range (14.0 beta 2–16.6.1, 16.7 RC 20H18, or 17.0) and must be a version the device model can actually run.
  • Processor architecture: Installation guides group devices into arm64 (A8), arm64 (A9–A11), and arm64e (A12–A17 Pro / M1–M2) because exploit and persistence paths differ across chip generations.
  • Installation-method availability: Having a supported firmware does not mean every installation tool works identically on every chip or sub-release (for example, some late iOS 15 builds use specific routes such as TrollRestore or TrollInstallerX/TrollHelperOTA depending on version and architecture).

For a full breakdown of firmware ranges and exceptions, see our TrollStore iOS Compatibility Guide.

Architecture Groups & Installation Routes

Even when two devices both run a supported iOS or iPadOS version, the exact installation method can differ by processor group and firmware sub-version.

  • arm64 — A8 / A8X group (e.g., iPad mini 4, iPad Air 2): Separate from A9–A11 devices in installation matrices; only applicable where a supported firmware (such as eligible iOS/iPadOS 14–15 builds) and installation route exist.
  • arm64 — A9–A11 group (e.g., iPhone 6s, iPhone 7, iPhone 8, iPhone X, iPad 5th–7th gen): Uses A9–A11-specific installation paths across supported iOS/iPadOS 14–16.6.1 (and 16.7 RC 20H18 where applicable).
  • arm64e — A12–A17 Pro & M1–M2 group (e.g., iPhone XR through iPhone 15, iPad mini 5/6, iPad Air 3–5, iPad Pro M1/M2): Uses arm64e installation routes (such as TrollHelperOTA, TrollInstallerX, or TrollRestore depending on exact OS version/build) up through iOS/iPadOS 17.0.

Do Not Guess the Installer by Model Alone: Always match your exact iOS/iPadOS version + build number + chip architecture against an up-to-date installation matrix (such as ios.cfw.guide) and our TrollStore Installation Guide before downloading any files.

How to Check Your Device & Firmware

  1. Open Settings > General > About on your iPhone or iPad.
  2. Note the Model Name and Software Version (tap the version number if you need to inspect the exact build number).
  3. Confirm your version is within 14.0 beta 2–16.6.1, 16.7 RC (20H18), or 17.0.
  4. Look up the matching architecture column and installation path for your exact version and device.

Common Device Compatibility Pitfalls

  • Confusing "supported device" with "currently supported firmware": An iPhone 13 or iPhone 15 has compatible hardware, but if it is updated to iOS 17.0.1 or later, TrollStore is not supported on that firmware.
  • Confusing public iOS 16.7 with iOS 16.7 RC (20H18): Only the 20H18 RC build is documented as supported; public 16.7 and later 16.7.x releases are excluded.
  • Assuming an IPA or third-party site unlocks newer iOS versions: No IPA file or unofficial wrapper can restore a patched CoreTrust vulnerability on an unsupported firmware.

Frequently Asked Questions

Does TrollStore work on all iPhone models?

No. Support depends on both the installed iOS version and whether a valid installation method applies to that exact firmware and device combination.

Does TrollStore support iPhone 6s and iPhone 7?

Yes, on eligible iOS 14–15 firmware versions within the documented range. Both belong to the arm64 architecture group.

Does TrollStore work on iPhone 15 and iPhone 15 Pro?

Both use arm64e chips, and firmware support applies to iOS 17.0 rather than iOS 17.0.1 or later versions.

Does TrollStore support iPad Pro M4?

No. iPad Pro M4 released after iPadOS 17.0 and is outside TrollStore's documented firmware compatibility range.

What is the difference between arm64 and arm64e?

arm64 and arm64e represent different Apple processor generations (for example, A8–A11 in arm64 versus A12–A17 Pro and M1/M2 in arm64e), which affect which installation steps apply.

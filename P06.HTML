TrollStore Supported Devices: Which iPhone and iPad Models Work?

TrollStore does not publish an official “supported devices” list. Instead, compatibility depends on two main factors: the device’s chip architecture and the installed iOS/iPadOS version.

This page focuses on device models and chip architecture. For the exact supported iOS versions, see the dedicated TrollStore iOS Compatibility page.

1. TrollStore Compatibility by Chip Architecture

TrollStore works on two main architecture groups:

Architecture Chip Range Typical Devices Notes
arm64 A8 – A11 iPhone 6s to iPhone X Older devices
arm64e A12 and newer iPhone XR / XS and all later models Newer devices

Installation methods can differ between these two groups, even on the same iOS version.

4. What Actually Determines Compatibility

  • Chip Architecture (this page) – decides which installation methods are available.
  • iOS / iPadOS Version (see P05) – the most important factor. TrollStore only works on specific firmware ranges.
  • Available Installation Method – even if both architecture and iOS version are fine, a working installer must exist for that combination.

5. Frequently Asked Questions

Does TrollStore work on iPhone 8?

Yes, the iPhone 8 (A11, arm64) can support TrollStore if it is running a supported iOS version.

Does TrollStore work on iPhone X?

Yes, same as iPhone 8 (A11).

Does TrollStore work on iPhone 11 / 12 / 13 / 14?

These models use arm64e architecture and can support TrollStore, but only on specific iOS versions.

Does TrollStore work on iPhone 15 / 16?

Hardware is compatible (arm64e), but most current iOS versions on these devices are outside the supported range.

Does TrollStore work on iPad?

Many iPad models can support it, depending on the chip and installed iPadOS version. Check the table above and the iOS compatibility page.

Is there an official list of supported devices?

No. The official TrollStore project only documents supported iOS/iPadOS versions and architecture requirements.

For the complete list of supported iOS and iPadOS versions, please check the TrollStore iOS Compatibility page.

That page contains the exact version ranges that currently work.
